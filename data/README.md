# Data publik pricelist Talented

- `refund.json` — ringkasan refund policy sekolah partner, dari dokumen resmi tiap sekolah. Diperbarui otomatis setiap bulan oleh Claude (jadwal tanggal 1). Status: Terverifikasi / Perlu konfirmasi / Tidak ditemukan. Website hanya menampilkan ringkasan untuk status Terverifikasi; status lain menampilkan `fallback_text`.

Dipakai oleh https://pricelist.talentededucationgroup.com (dibaca langsung, dengan cache-busting).
